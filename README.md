A tiny deterministic trend bot for hourly Solana bars: it holds an asset only when its 12h EMA sits above its 48h EMA with positive 24h momentum, scales in over 6 bars, and sits in cash otherwise — beating buy-and-hold by staying out of falling markets.

## Run it

```sh
node main.ts
```
